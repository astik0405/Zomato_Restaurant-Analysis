# Zomato Restaurants Analysis Dashboard 🍽️📊 | Power BI Project

## 📌 Project Overview
This project is an interactive **Power BI dashboard** built to analyze **Zomato restaurant data** across multiple countries and cities.  
It provides meaningful insights into restaurant distribution, ratings, cuisines, votes, online delivery, and table booking trends.

The dashboard helps in understanding:
- Global restaurant presence
- Popular cuisines
- Customer rating patterns
- Service availability (online delivery & table booking)

---

## 🎯 Objectives
- Analyze restaurants by **country and city**
- Track key KPIs like **total restaurants, average rating, votes, cuisines**
- Understand **cuisine-wise restaurant count**
- Compare **average rating by cuisine**
- Analyze service trends: **Online Delivery** and **Table Booking**
- Enable dynamic filtering using slicers (Country & Year)

---

## 🛠️ Tools & Technologies Used
- **Power BI Desktop**
- **DAX (Data Analysis Expressions)**
- **Excel dataset**
- Data Modeling & Interactive Visualizations

## 📂 Dataset Information
The dataset contains restaurant-level details such as:

## 📌 Dashboard Features

### 🌍 Country Filter
- Select any country (India, Australia, Brazil, etc.)
- Instantly updates all visuals based on selection

### 🗓️ Year Filter
- Analyze trends year-wise using a year slicer

### 🗺️ City-wise Restaurant Distribution (Map)
- Displays restaurant presence across world cities using a map visual

### 🍲 Cuisine Analysis
- **Cuisine-wise count of restaurants**
- **Cuisine-wise average rating**
- Helps identify most popular cuisines and customer preferences

### 🚚 Online Delivery Analysis
- Pie chart showing restaurants offering online delivery vs not offering

### 🪑 Table Booking Analysis
- Donut chart showing restaurants providing table booking facility vs not

---

## 📈 Key Insights
- Restaurants are distributed across 13 countries and 80 cities
- Some cuisines have a higher restaurant count but lower average ratings
- Online delivery services are available for a major portion of restaurants
- Table booking availability is lower compared to online delivery in many countries
